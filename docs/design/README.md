# 资源调度设计资料

确认后的设计稿、图标方案和视觉规范应保存在本目录，不长期存放在系统盘临时目录。

当前已确认：

- 任务卡六区以用户最后的示意图为准：上排“开始时间｜状态图标｜结束时间”，下排“航班号｜任务名｜机位”。
- 计算开始时间确认沿用 startTime / scheduleStartTime；航班号和机位由接口返回。
- 上下列对齐，不画内部表格线；缺失字段留空，任务名只显示一次。
- 上排状态栏在参考脚本基础上显示：notifyStatus 通知图标 → locked 锁定／解锁图标（固定展示）→ taskStatus 对应图标 → 状态单字。locked 为 false、null 或缺失时默认 false，显示用户提供的解锁图标。
- 通知状态 0 为空心框，1 为青绿色实心框，2 为蓝色勾选框，3 为红色叉号。
- 保留已设计的时钟、终点旗、播放、勾选、警示等任务图标，并配“未／到／始／结／阻／继／取／恢／挂”单字。
- 状态组之间间隔 4px，任务图标与单字间隔 2px；窄卡先隐藏单字、缩减间距，优先保留锁定／解锁和任务图标，极窄时保留锁定／解锁图标。
- 下排保持“航班号｜任务名｜机位”；锁图标已移至上排状态栏。
- 任务卡左侧补齐 4px 实色页签，颜色对应任务状态，内容留出左内边距。
- 拥挤程度每个重叠区间只显示一条黄色或红色细线。

设计确认后应删除 C 盘可视化临时目录中的对应候选文件，只保留项目内必要源文件和最终预览图。
